# 字 Графемы — версия 0.2

Автономное веб-приложение на русском языке для изучения 214 ключей Канси и 30 фонетических семейств китайских иероглифов.

## Использование

- Откройте `index.html` в современном браузере (на компьютере работает без интернета).
- Для удобной работы на iPhone разместите `index.html` на GitHub Pages или другом HTTPS-хостинге, затем откройте сайт в Safari и выберите «Поделиться → На экран Домой».
- Для GitHub Pages достаточно загрузить `index.html` в корень отдельного репозитория и включить Pages → Deploy from a branch.
- Прогресс сохраняется в localStorage для конкретного домена и браузера. Экспорт/импорт доступен во вкладке «Прогресс».

## Ограничения

- Три категории — учебная эвристика, один компонент может выполнять несколько функций.
- Система из 214 ключей Канси не включает все фонетические компоненты китайского языка.
- Часть ключей редкие или архаичные. Браузерный синтез речи удалён: доступны только реальные аудиофайлы. По умолчанию подключена лишь демонстрационная открытая запись 五 (wǔ) с Wikimedia Commons, требующая интернета. Остальные записи необходимо импортировать.
- Данные упрощённых вариантов приведены только для части ключей; традиционный ключ сохранён в данных.
- Упражнения пока проверяют значения; расширенная система интервальных повторений запланирована на следующие версии.

Все материалы приложения работают без серверной части и не загружают личный прогресс в интернет.

## Аудио 0.2

Вкладка «Прогресс» → «Загрузить аудиофайлы» принимает несколько MP3/OGG/M4A/FLAC/WAV файлов. Имена должны начинаться с пиньиня **без диакритики и с цифрой тона**, например `qing1.mp3`, `qing2.mp3`, `ma3.ogg`, `ma5.mp3` (5 — нейтральный тон). Аудио сохраняется в IndexedDB и остаётся доступно офлайн после импорта в том же браузере и домене. Экспорт учебного прогресса не включает эти аудиофайлы.

Подходящие источники реальных записей: Shtooka «Base Audio Libre De Mots Chinois»; отдельные наборы имеют различные Creative Commons лицензии (например, CC BY 2.0 FR и CC BY-SA 3.0 US). Перед включением файлов в распространяемый пакет проверяйте условия лицензии, атрибуцию и чтения. Исходная подборка: https://github.com/trevorld/mandarin_audio_utilities . Имена файлов набора могут содержать дополнительные суффиксы, импортёр их допускает после подчёркивания или дефиса.

Знаки из 214 ключей без явно проверенного чтения сознательно не озвучиваются. Для редких ключей требуется отдельная словарная разметка чтений; у многозвучных иероглифов нужно выбирать контекст.


## 0.3 — записи носителя языка

Онлайн-аудио: [audio-cmn](https://github.com/hugolpz/audio-cmn), слоги, произнесённые Chen Wang, CC BY-SA. Звук воспроизводится по HTTPS из репозитория при наличии интернета. Это реальные записи человека, не Web Speech API. Доступность каждой ссылки на устройстве пользователя не гарантируется. Для неизвестного чтения, многовариантного пиньиня или нейтрального тона приложение не подставляет неверную запись. Импорт локальных файлов сохранён как задел, но не переключается автоматически в режиме онлайн. Для автономного режима потребуется включить отдельную загрузку и проверку файлов.
