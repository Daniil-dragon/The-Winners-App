# 字 Графемы — версия 0.5 (прописи)

Самостоятельное приложение для 214 ключей Канси и 30 фонетических семейств с карточками, проверкой значений, озвучкой и сохранением прогресса.

## Добавлено в 0.5

- Переключение вида знаков «Кистевой · кайшу» / «Стандартный» на страницах каталога, семейств, карточек и прописей. Для текста используется каллиграфический системный шрифт, доступность и вид которого зависят от установленного шрифта устройства. **Проверенные контуры настоящих отдельных черт используются внутри режима прописей**, независимо от системного шрифта.
- Вкладка «✍ Прописи» и кнопки для перехода к написанию из карточек, описаний ключей и фонетических семейств.
- Просмотр порядка черт: целая анимация, отдельная черта, шаг вперёд/назад, повтор.
- Три уровня: обведение контуров, письмо по слабому образцу, письмо по памяти без контуров.
- Автоматическая проверка количества и последовательности движений, направления и примерной геометрии на основе библиотеки Hanzi Writer. Уровень точности ограничен алгоритмом; это не оценка художника-каллиграфа.
- Сообщения об ошибках, подсказки и сохранение количества завершённых попыток и лучшего результата для каждого знака, отдельно от прогресса карточек.
- Экспорт/импорт результатов письма вместе с прогрессом карточек. Используется прежний ключ localStorage для существующего прогресса карточек, его данные не должны теряться при замене `index.html` на прежнем адресе сайта.

## Требования и ограничения

- Для работы **анимации и проверки** при первом обращении к иероглифу нужен интернет: Hanzi Writer 3.5 загружается с CDN, а векторные данные отдельных черт — из открытого репозитория hanzi-writer-data через CDN. В ZIP эти сторонние пакеты пока не включены; отсутствие соединения или конкретного знака будет показано пользователю.
- Не гарантировано наличие векторных данных для каждого редкого традиционного ключа или отдельного графического компонента. Приложение не выставляет фиктивную оценку, когда данных нет.
- Шрифт кайшу на карточках зависит от iOS; максимально точные формы — в обучающем поле Hanzi Writer.
- Полноценное ручное тестирование на iPhone/iOS Safari необходимо. Проверка JavaScript на синтаксические ошибки выполнена, но графический браузер в среде сборки заблокирован.
- Озвучка из 0.4 остаётся онлайн, с диагностикой двух источников. Реальная полнота и качество аудиозаписей не гарантированы.

## Установка

Распакуйте архив и загрузите `index.html` в **корень того же репозитория GitHub Pages** взамен старого. При использовании того же HTTPS-адреса локальный прогресс браузера должен сохраниться. Перед обновлением рекомендуется экспортировать прогресс в разделе «Прогресс».

## Аудио 0.5.4: дополнительные источники

Для фонетических основ 朱 (zhū), 巴 (bā) и 申 (shēn) подключены дополнительные записи слогов Wikimedia Commons. Эти записи произнесены носителями китайского, но **не являются записями именно данных иероглифов**: zhū — 猪, bā — 八, shēn — 深. Источник: Shtooka Project (Wei Gao и Vion Nicolas), лицензия CC BY 2.0 France; https://creativecommons.org/licenses/by/2.0/fr/ . Файлы: https://commons.wikimedia.org/wiki/File:Zh-zhū.ogg , https://commons.wikimedia.org/wiki/File:Zh-bā.ogg и https://commons.wikimedia.org/wiki/File:Zh-shēn.ogg .

Для 朱, 召, 巴 и 及 при отсутствии отдельной HSK-записи знака приложение воспроизводит доступную запись совпадающего слога с нужным тоном и прямо об этом сообщает. Выбранный пользователем лучший источник и прежний прогресс сохраняются. Проверка воспроизведения OGG на iPhone требуется отдельно.


## Версия 0.5.5 — озвучка и пиньинь группы 2

Пиньинь с тонами добавлен ко всем 148 ключам учебной группы 2 (одна основная учебная форма чтения для каждого). Поиск, словарь, подробные карточки и карточки на повторение показывают чтение. Для «一» указано yī; контекстные изменения тона нужно изучать отдельно. Данные о чтениях сопоставлены с традиционным набором 214 ключей Канси и дополнительно отредактированы под современные упрощённые формы. См. https://gist.github.com/fabiovalse/aeec64f31496e49dac23469ab7e44cbe .

Кнопка «Слог» использует запись соответствующего слога в audio-cmn, а «Знак» пытается воспроизвести конкретный иероглиф; при отсутствии записи в источнике включается слог с нужным тоном и выводится пояснение. Это не гарантия наличия отдельных записей для всех знаков; для редких знаков возможны ошибки источника. Выбранные пользователем варианты сохраняются.

Для фонетиков 朱 (zhū) и 召 (zhào) появился третий вариант «Ещё голос»: записи соответственно 猪 и 照 с теми же современными чтениями (не записи исходных иероглифов), из https://github.com/hugolpz/audio-cmn (Yue Tan, CC BY-SA). Доступность и качество требуется проверить на iPhone.


## Версия 0.5.6

В карточках ключей учебной группы 2 появились кнопки «♥ Лучше слог» и «♥ Лучше знак». Предпочтения используют тот же локальный ключ `hanzi_radicals_audio_preferences_v1`, что и фонетические семейства, и сохраняются между открытиями приложения.

В общем каталоге ключи со статусом «Знаю» выделены зелёным контуром и фоном, ключи «Повторить» — оранжевым, неизученные остаются нейтральными. Статусы считываются из существующего прогресса, без миграции или его сброса.


## Версия 0.5.7 — удобство и словарные значения

- Исправлены русские формы счёта черт (1 черта, 2–4 черты, 5–20 черт, кроме 11–14).
- На странице ключей и в разделе фонетики переписаны вводные объяснения для начинающих.
- В прописях элементы управления чертами перемещены к режиму «Порядок черт», а «Тренировка» и доступный только внутри неё «Повторить» располагаются ниже поля.
- В фонетических семействах кнопка «▶ Слушать» воспроизводит сохранённый основной источник. Дополнительный вариант для 朱 и 召 можно выбрать через «♥ Ещё голос»; все ранее выбранные источники остаются в localStorage. Кнопки «✕» отмечают неудачную запись в прежнем отчёте (старые отчёты сохраняются), а кнопка «Слог вместо знака» убрана.
- Уточнены формулировки значений 13 ключей (№ 10, 90, 103, 113, 126, 138, 146, 153, 163, 170, 178, 181, 205), в том числе различие между значением радикала и самостоятельного иероглифа. Это **не полная лексикографическая экспертиза всех 214 ключей**. Для дальнейшей сверки следует использовать независимые словари и проверять контекст; определения trainchinese целиком не копировались.

Не меняются ключи сохранения прогресса, результаты прописей и аудиопредпочтения. Изменения в интерфейсе требуют проверки на iPhone.
